# 02 · Cell mapping of sheep complex traits

Workflow: sheep GWAS → lineage/cell association → representative contexts → PCC candidates and pathway analyses → predicted network response.

The target panels are Fig. 6a (15 traits × 8 lineages), Fig. 6b–e (ALLGE3–conceptus and chest-depth–lung), Fig. 6f (PCC candidates, pathway activity and KEGG enrichment), Extended Data Fig. 6a–f (global/TRS and tissue extensions), and Extended Data Fig. 6g (ear-length–rectum C7+ stromal-cell perturbations).

Only partial summary plotting and PCC ranking scripts are currently included. The specified full association, representative-context, pathway, and perturbation workflows remain documented gaps.
