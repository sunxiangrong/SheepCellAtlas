# Candidate genes and pathways

The intended sequence is to derive candidate genes from the scPagwas trait/context results, rank genes with the declared PCC rule, and run pathway enrichment using a documented background. `00_rank_candidate_contexts.py` currently ranks selected context-specific PCC tables; it is not the full candidate-gene extraction or enrichment pipeline. Record gene ID mapping, PCC thresholds, enrichment method, database release, and background universe.
