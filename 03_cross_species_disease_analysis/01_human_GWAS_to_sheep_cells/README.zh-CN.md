# 人类疾病 GWAS 映射到羊细胞背景

## 预期顺序

1. 获取各疾病 GWAS/COJO 结果，记录来源、版本、组装版本和坐标约定。
2. 运行 `00_prepare_500kb_gwas_loci.py --help`，按参数截取每个性状的合并位点窗口并输出处理清单。该脚本不做原始 GWAS 协调或坐标转换；输入须已完成相应汇总与位点合并。
3. 统一变异 ID、等位基因和基因映射；准备羊图谱及疾病对应的人类参考对象/细胞标签。
4. 运行准确版本的 scPagwas，并按谱系、组织和细胞类型汇总得分及 FDR。
5. 输入已汇总的关联与表达结果后，再运行 `04_asthma_lung_airway_case.py` 生成哮喘肺/气道案例结果。羊/人同源基因表的 hg19 或 hg38 符号列需通过 `--human-ortholog-column` 明确指定。

本目录尚未包含所有疾病的完整可移植流程。哮喘脚本只处理案例阶段，不能代替 GWAS 映射。坐标转换和按疾病/组织运行 scPagwas 的任务编排仍需源代码审查和参数化。
